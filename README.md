# AWS Cloud Security Project

## 📌 Project Overview

This project is a beginner-friendly AWS Cloud Security website created to demonstrate fundamental concepts of cloud security and AWS Identity and Access Management (IAM).

The project presents important AWS security principles such as IAM users, IAM roles, IAM policies, Multi-Factor Authentication (MFA), and the principle of least privilege.

## 🎯 Objectives

* Understand basic AWS IAM concepts
* Learn fundamental cloud security practices
* Demonstrate the principle of least privilege
* Create a professional cloud-focused web project
* Deploy a static website using GitHub Pages

## 🛠️ Technologies Used

* AWS IAM concepts

## 🔐 Key Security Concepts

### IAM Users

IAM users represent identities that can be assigned permissions to access AWS resources.

### IAM Roles

IAM roles provide temporary permissions to users, applications, or AWS services.

### IAM Policies

IAM policies define which actions are allowed or denied on AWS resources.

### Multi-Factor Authentication

MFA provides an additional layer of security for AWS accounts.

### Least Privilege

Users and applications should receive only the permissions required to perform their tasks.
